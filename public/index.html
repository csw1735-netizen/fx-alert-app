1️⃣ 로그인

1. 텔레그램에서 봇과 대화를 시작하고 아무 메시지나 하나 보내기
2. 브라우저에서 https://api.telegram.org/bot<봇토큰>/getUpdates 접속해서 내 Chat ID 확인
3. 아래에 Chat ID와, 처음이면 원하는 4~8자리 숫자 PIN을 정해서 입력 (다음부터는 같은 PIN으로 로그인)
4. 다른 기기에서도 같은 Chat ID + PIN을 입력하면 항상 내 설정 그대로 불러와집니다.

2️⃣ 변동 알림 기준

이상 변동 시 알림 (5분마다 서버가 체크)

3️⃣ 정기 알림

정기 알림은 한국시간 06:00~23:59에만 오며, 이 옵션을 켜면 변동 알림도 주말엔 오지 않아요.
Chat ID + PIN으로 본인 인증된 사용자만 자신의 설정을 바꿀 수 있어요. 다른 사람의 알림 설정은 볼 수도 바꿀 수도 없습니다.
